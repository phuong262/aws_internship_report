This page summarizes the eight-week internship, from **22/06/2026** to **15/08/2026**, completed as part of the **First Cloud AI Journey (FCAJ)** program. During the internship, I participated in developing **Smart Docs AI**, a document question-answering and knowledge extraction platform based on Retrieval-Augmented Generation (RAG) and an AWS serverless architecture.

My responsibility in the project focused on the document ingestion and processing flow: configuring Amazon S3 events, developing AWS Lambda functions that run automatically when files are uploaded, calling Amazon Textract to extract text, and combining fragmented lines and paragraphs into complete content.
