### 1. Truy cập kho lưu trữ GitHub

* Truy cập kho lưu trữ GitHub của dự án: https://github.com/THL2410/SmartDocs
* Chọn **Code** → **HTTPS**.
* Sao chép URL của kho lưu trữ.

![github](/images/5-Workshop/5.2-Prerequisite/sourceCode.png)

### 2. Sao chép (Clone) mã nguồn về máy tính

* Mở **Terminal** hoặc **PowerShell** tại thư mục mà bạn muốn lưu trữ mã nguồn.
* Chạy lệnh sau:

```bash
git clone https://github.com/THL2410/SmartDocs.git
```
