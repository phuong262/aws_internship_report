During the First Cloud AI Journey program, I researched and shared three technical articles with the AWS Study Group VN community. These articles focus on system monitoring, database administration, and automated document processing on AWS.

### [Blog 1 - Mastering Serverless Monitoring with Amazon CloudWatch](3.1-Blog1/)

This article explains the role of Amazon CloudWatch in centralizing logs, tracking metrics, building dashboards, and configuring proactive alerts for Serverless systems. These capabilities help operations teams detect incidents early and reduce troubleshooting time in distributed architectures.

### [Blog 2 - Optimizing Database Operations with Amazon RDS](3.2-Blog2/)

This article introduces how Amazon RDS reduces database administration effort through automated backups, point-in-time recovery, Multi-AZ deployments, Read Replicas, and data encryption. It provides a suitable foundation for applications that require high availability, scalability, and strong security.

### [Blog 3 - Automating Document Extraction with Amazon Textract and Serverless](3.3-Blog3/)

This article describes an event-driven document-processing workflow using Amazon S3, AWS Lambda, and Amazon Textract. The solution automatically extracts printed text, handwriting, and tables, then standardizes the results as JSON for subsequent storage or analysis.
